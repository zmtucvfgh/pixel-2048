隐私：本游戏不采集任何个人信息，无需注册登录，仅在本机保存游戏进度与最高分。

## 4. B站小游戏提交流程（按顺序做）

1. 注册小游戏开发者：https://miniapp.bilibili.com/small-game-doc/guide/account
   （个人实名即可；企业主体更顺）
2. 安装哔哩哔哩开发者工具：https://miniapp.bilibili.com/small-game-doc/guide/cli
3. 在本仓库执行：`npm run build:bilibili` → 得到 `dist/bilibili/`
4. 打开开发者工具 → 新建项目 → 目录选 `dist/bilibili` → 填你的 AppID（先用「测试号」也可）
5. 本地调试：确认能运行、无报错；后台确认「启动成功」埋点有数据（审核必查）
6. 上传为开发版：填版本号 1.0.0 与更新说明
7. 后台扫码真机预览：重点过一遍第 A/C 节真机项（见 RELEASE-CHECKLIST）
8. 补材料：名称、图标、简介、截图、测试说明、隐私说明（本文档第 1~3 节）
9. 资质：小游戏备案 + ICP 备案（按后台指引，需短信核验）；软著可选
10. 从已验证的开发版提交审核 → 通过后**手动点「发布」**

## 5. GitHub 发布流程

方案 A（推荐，30 秒）：
1. 打开 https://github.com/new
2. Repository name 填 `pixel-2048`，选 Public，**不要**勾选 Add README / .gitignore / License
3. 点 Create repository
4. 把仓库地址发给我（如 `https://github.com/Abduxkurr/pixel-2048.git`），我执行 push，
   首次会弹出 GitHub 授权窗口，点 Authorize 即可

方案 B（让我全自动）：
在 WorkBuddy 设置 → Agent → 开启「浏览器控制」，并给 Chrome 装 WorkBuddy 扩展；
完成后告诉我，我来自动建仓库并推送。
